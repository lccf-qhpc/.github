## LCCF: HPC-QPU integration 👋

The Leadership Class Compute facility project is an NSF-funded initiative (NSF #2212090, NSF #2323116) to deploy next-generation cyberinfrastructure. As part of the components, the National Center for Supercomputing Applications at UIUC is undergoing the deployment of an integrated HPC-QPU system. This organization contains emerging codes that implements necessary systems programs to access, program and reach a superconducting, transmon-based QPU at the Pfaff Lab (IQUIST Testbed).
